# Manager — agent guidance

- Read `.specify/memory/constitution.md` before planning or implementing. It is binding.
- Product context: `docs/vision.md`. Milestones and spec order: `docs/roadmap.md`.
- Workflow: Spec Kit skills (`/speckit-specify`, `/speckit-clarify`, `/speckit-plan`, `/speckit-tasks`,
  `/speckit-implement`). One branch + PR per spec.
- Football Manager is the design benchmark. Check how FM does something before designing it.
- In-game text is PT-BR; code, comments and docs are English.
- Never commit real player/club data (it belongs in the private `manager-data` repo).
- When the owner reports an annoyance from other games, add it to the pain-point log in `docs/roadmap.md`.
- `prototype/` is archived reference code. Do not extend it.
